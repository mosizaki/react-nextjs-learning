- How to use useState
- How to update state
- How state changes cause UI re-renders
- How to build state-driven UI
- How to use boolean state for toggles

## What I built

- Counter
- Like button
- Show/hide password input
- Dark mode toggle

## Key concepts

State is data that a React component remembers and can update over time.

When state changes, React re-renders the component and updates the UI.
