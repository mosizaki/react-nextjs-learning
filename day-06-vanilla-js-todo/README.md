# Day 6 — Vanilla JavaScript Todo App

This is a mini todo app built with HTML, CSS, and vanilla JavaScript.

## Features

- Add todo
- Delete todo
- Mark todo as completed
- Save todos to localStorage
- Todos remain after page refresh

## What I learned

- DOM selection
- Form submit events
- preventDefault
- Creating elements with JavaScript
- Rendering data to the page
- Array methods: push, filter, map
- localStorage
- JSON.stringify and JSON.parse

## How to use

1. Type a todo in the input
2. Click Add or press Enter
3. Check a todo to mark it completed
4. Click Delete to remove it
5. Refresh the page and todos will still be there
