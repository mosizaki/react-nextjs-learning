# React + Next.js Learning Journey

This repository documents my day-by-day learning path toward becoming job-ready for a frontend developer position using JavaScript, React, Next.js, Git, and modern frontend tools.

The goal of this repository is not only to watch tutorials, but to build practical exercises and small projects every day. Each folder represents one day or one topic in the learning plan.

## Main Goal

To develop strong frontend development skills by learning and practicing:

* JavaScript fundamentals
* React fundamentals
* React state management
* React Router
* Next.js App Router
* TypeScript
* API fetching
* Forms and validation
* Responsive design
* Component-based architecture
* Git and GitHub workflow
* Portfolio-level project building

## Learning Method

Each day follows this structure:

1. Learn one focused concept
2. Practice with small examples
3. Build a hands-on exercise or mini project
4. Commit the work to GitHub
5. Write notes about what was learned

The main rule of this repository is:

> Every day should produce code, not just watched tutorials.
